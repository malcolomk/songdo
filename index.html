시스템 주요 메뉴 및 기능 안내

입/출고 등록 (Register) 용도: 창고에 물건이 새로 들어오거나 나갈 때 수량을 기록하는 곳입니다.
특징: 여러 개의 품목을 '카트'에 담아두었다가 [일괄 저장] 버튼 한 번으로 빠르게 작업할 수 있습니다.
재고 조회 (Stock) 용도: 현재 창고에 있는 물건의 전체 수량과 창고 보관 위치를 실시간으로 검색할 수 있습니다.
특징: 품목명이나 번호로 즉시 검색이 가능하며, HFB(부서별) 필터 기능을 지원합니다.
오더 요청 (Order) 용도: 매장에 볼륨이 낮은 제품들을 입고 오더 요청 하는 기능입니다.
특징: 해당 오더들을 바탕으로 프리노트 작성이 들어갑니다.
창고 챙기기 (Pick List) 용도: 매장에서 요청(오더)한 물품 중, 현재 창고에 실제 재고가 있는 품목만 자동으로 모아서 보여주는 대기열입니다.
특징: 챙겨야 할 항목 숫자가 앱 하단 뱃지 알림으로 표시됩니다. 물건을 꺼낸 뒤 [챙김 완료]만 누르면 즉시 출고(재고 차감) 처리가 완료됩니다.
피택 (P-Tag) 요청 용도: 매장에 누락된 P-TAG, 렉라벨이 필요한 아티클을 등록해 엑셀로 한번에 추출할 수 있습니다.
버그 발견시 지인에게 알려주세요!

창고 재고 관리의 중요성

올바른 재고 관리는 원활한 스토어 운영의 핵심입니다. 입고와 출고 시 정확한 수량 확인과 정확한 구역 지정을 철저히 하여 재고 오차를 방지해 주시기 바랍니다.

※ 본인의 정확한 기록이 다른 동료들의 업무 효율을 높입니다.

송도 스토어 재고관리 메뉴얼

환영합니다!

이 시스템은 송도 스토어의 창고 재고를 실시간으로 정확하게 파악하고, 동료들과 원활하게 소통하기 위해 만들어졌습니다.

입출고를 기록할 때는 반드시 정확한 품목명, 수량, 구역을 확인 후 등록해 주시기 바랍니다.

주요 기능 안내

  • 입출고 등록: 물건을 입고하거나 출고할 때 아티클 번호 또는 이름 입력으로 기록을 남깁니다.
  • 오더 요청: 필요한 물품이 있을 경우 '오더' 탭에서 요청을 보낼 수 있습니다.
    (해당 내역을 바탕으로 고양점 프리노트 오더의 기반이 됩니다.)
  • 창고 챙기기: 동료가 요청한 오더를 확인하고, 창고에서 물품을 준비한 뒤 매장 리플 후 완료 처리합니다.

주의 사항

잘못된 재고 등록은 송도 스토어뿐만 아니라 고양점에도 업무 지장을 초래합니다. 항상 본인이 직접 확인한 수량만 등록해 주세요.

※ 문의사항 및 버그 발생시 지인에게 문의해주세요.
